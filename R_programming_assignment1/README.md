# R Programming Assignment #1

## 🧮 Overview

In this assignment, I demonstrated fundamental R programming skills to manipulate datasets, compute descriptive statistics, and generate basic visualizations. This activity reinforces concepts including data types, vectors, and probability-related computations.

## 🎯 Learning Objectives

This assignment taught me:

* Write and execute R scripts using best practices.
* Create and manage vectors, data frames, and factors.
* Apply descriptive statistical functions (mean, median, sd, etc.).
* Produce simple data visualizations (histograms, scatter plots).
* Use R as a tool to analyze real data.

## 📌 Tasks

1. Load and inspect the provided dataset
2. Create summary statistics and detect outliers
3. Visualize variable distributions
4. Write functions to compute basic probabilities
