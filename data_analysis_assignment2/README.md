# Data Analysis Assignment #2 (Inference & Regression)

## 📈 Overview

This assignment builds on hypothesis testing, confidence intervals, and regression methods. I will analyze a dataset and provide business-oriented insights.

---

## 🎯 Learning Objectives

* Conduct inferential statistical analysis
* Perform regression modeling and evaluate model fit
* Communicate significance vs. practical impact
* Use R effectively for statistical reporting

---

## 📌 Tasks

1. Conduct at least two hypothesis tests
2. Construct confidence intervals for key estimates
3. Fit and analyze a regression model
4. Discuss implications of results for decision-making
