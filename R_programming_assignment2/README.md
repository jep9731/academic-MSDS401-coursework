# R Programming Assignment #2

## 🔁 Overview

This assignment focuses on applying R to evaluate relationships between variables using hypothesis testing and simple linear regression.

## 🎯 Learning Objectives

This assignment taught me:

* Conduct and interpret hypothesis tests in R.
* Create and analyze scatter plots with regression lines.
* Fit and evaluate linear regression models.
* Compute correlation and interpret strength/direction.
* Present statistical findings clearly and accurately.

## 📌 Tasks

1. Load dataset and perform exploratory summaries.
2. Conduct correlation analysis.
3. Fit a simple linear regression model.
4. Evaluate model significance and predictive accuracy.
5. Provide interpretations with supporting visuals.

## Run:

To run the file, download the `Pasaye_Joshua_R_Assignment_2.Rmd` and run the script. No other data is neccessary.
